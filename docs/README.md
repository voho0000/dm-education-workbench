**為什麼放在版控裡。** 這份檔案原本只存在於暫存目錄，暫存區一清就沒了——
批次執行器也是同樣的原因消失過一次。已發布的網址還在，但要改就得先把內容
抓回來，而抓回來的東西夾著平台的 frame 外殼，得手動剝掉。會用到的東西就該
進版控。

**改它的方式。** 直接編輯這個檔案，然後重新發布時**要指定原本的網址**，否則
會產生一個新的、與現有連結無關的 artifact。

**內容範圍。** 這份文件含衛教模組與自我照護模組的全文（那些本來就在
`app/lib/` 裡）、指引門檻的事實陳述與頁次、以及一份用合成資料跑出來的報告
範例。**不含任何病人資料，也不含指引原文。** 修改時請維持這條線。

發布時是私有的，要給人看必須從該頁的分享選單開權限。
